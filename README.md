# Speed Control of DC Motor Using PWM
## AIM

To control the speed of a DC motor using PWM (Pulse Width Modulation) signal generated by Arduino UNO with the help of a potentiometer.

# COMPONENTS REQUIRED

1. Arduino UNO

2. Potentiometer

3. NMOS Transistor

4. 9V Battery

5. DC Motor

6. Connecting Wires

7. Breadboard

# ALGORITHM

1. Connect the DC motor circuit with Arduino UNO using an NMOS transistor.

2. Connect the potentiometer to the analog input pin of Arduino.

3. Initialize the motor control pin as an output.
 
4. Read the analog value from the potentiometer.

5. Convert the analog value into a PWM value using the map() function.

6. Send the PWM signal to the motor using analogWrite().

7. Vary the potentiometer to change the PWM duty cycle.

8. The DC motor speed increases or decreases according to the potentiometer value.

# WORKING PRINCIPLE

- The potentiometer controls the input voltage given to the Arduino.

- Arduino reads the analog value between 0 and 1023.

- The value is converted into a PWM range of 0 to 255.

- PWM controls the power supplied to the DC motor.

- Higher PWM value increases motor speed, while lower PWM value decreases motor speed.

# PROGRAM

```
int MPin = 9;   //motor pin
int Analog = A0;  // Analog Input
int Ainp = 0; // Read analog input, initialized to zero  
  
void setup()
{
  
  Serial.begin(9600);
  pinMode(MPin, OUTPUT);
  pinMode(Analog, INPUT);
}

void loop()
{

Ainp = analogRead(A0);

int Speed = map(Ainp, 0, 1024, 0, 255);
delay(100);
Serial.println(Speed);
analogWrite(MPin, Speed);  

}
```
